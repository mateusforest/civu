# Civu

Gestão municipal integrada. Prefeitura, cidadãos, empresas e fornecedores no mesmo lugar.

## Executar

Abra `index.html` no navegador ou sirva a pasta com um servidor estático. O protótipo não exige instalação nem servidor de aplicação. A renderização exportada preserva o estado demonstrativo no navegador.

Para editar, altere `src/civu.html` e execute `python scripts/build.py` com Python 3. Fontes e bibliotecas visuais do invólucro são carregadas de CDNs; a operação dos módulos é simulada localmente.

## Conteúdo

- `index.html`: versão completa para abrir fora do Codex.
- `src/civu.html`: fonte editável do protótipo integrado.
- `assets/brand/`: marca vetorial adaptada para interface e referências visuais fornecidas.
- `docs/`: documento mestre do produto em Word e PDF.
- `archive/prototypes/`: versões históricas, preservadas para rastreabilidade.
- `output/`: estudos de identidade realizados durante o projeto.

## Escopo preservado

Gestão municipal e painel do prefeito; portais do cidadão, das empresas e dos fornecedores; licitações, tributos, obras, finanças, automações e IA, permissões, auditoria, integrações e HelpU. Menus agrupados e recolhidos, com navegação conforme a área.

## Estado do produto

Protótipo demonstrativo com dados fictícios. Login gov.br, bancos, PNCP, NFS-e, mensagens e aprovações são simulações locais. Não inserir dados pessoais, credenciais ou documentos reais. O protótipo não implementa autenticação segura, backend municipal ou integrações oficiais de produção.

Nome atual: **Civu**. Os arquivos históricos mantêm nomes e identidade antigos intencionalmente. A marca vetorial de interface é uma adaptação do conceito fornecido e requer validação final de identidade e registro.
